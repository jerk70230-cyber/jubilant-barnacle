# Cold Car — атмосфера: туман войны, метель, PS1-фильтр, курсор, клики

## Быстрый старт (30 секунд)

1. Открой сцену `SampleScene` в Unity.
2. Дождись компиляции скриптов.
3. Меню сверху: **Tools → Cold Car → Setup Atmosphere Scene**.
4. Жми **Play**. Всё.

Что произойдёт:
- Сцена погрузится в темноту (ambient + туман), Directional Light притушится.
- На машине появится **конус света — туман войны**, который поворачивается
  в ту сторону, куда указывает курсор мыши (изометрия: луч из камеры → земля → направление от машины).
- Пойдёт **метель** (частицы + туман).
- Включится **PS1-пиксельный фильтр** (низкое разрешение, квантование цвета, дизеринг, сканлайны).
- Курсор станет **кастомным кольцом-прицелом**; при наведении на деталь машины он загорается.
- Все детали машины (двери, колёса, капот, багажник, руль) — **кликабельны**: подсветка при наведении,
  при клике — лог `[Car] Clicked part: ...` и событие `CarPartClickable.PartClicked`.

## Где что настраивать

### `--- ATMOSPHERE ---` (объект в иерархии)

**FogOfWarController (туман войны + темнота):**
Туман войны теперь — **экранный оверлей**: работает на любых материалах, даже
unlit (поэтому сцена реально темнеет). Всё, что вне конуса от машины к курсору,
+ маленький «пузырь» видимости вокруг машины — уходит в темноту с синеватым оттенком.
- `car` — от какой машины рисуется конус.
- **Тьма**: `darkness` (1 = глухой туман войны, вне конуса мир ровно цвета `darkColor`, ничего не просвечивает; меньше 1 = слегка проглядывают силуэты), `darkColor` (цвет полной тьмы).
- **Форма видимости**: `coneLength` (длина конуса в высотах экрана), `coneHalfAngleDeg` (полуугол, °), `carBubbleRadius` (видимость вокруг машины), `coneEdgeSoftness` (мягкость краёв).
- **«Фонарик»**: `revealBrightness` (гамма-подъём внутри конуса — тёмные машины начинают читаться, белое не выгорает), `revealLift` (плоская добавка для совсем чёрных материалов).
- Важно: туман войны применяется **после** пост-обработки — bloom/виньетка не могут «протечь» сквозь тьму.
- **Окна**: `windowVisibility` (0..1) — грязные/запотевшие окна укорачивают конус до `coneLengthWhenBlind` и сужают до `coneHalfAngleWhenBlind`.
  В игре тестовые клавиши **[** и **]** (грязнее/чище). API: `FogOfWarController.Instance.SetWindowVisibility(v)`.
- Сцена: `ambientColor`, `fogDensity`, `fogColor`, `directionalLightDim` (для lit-материалов).
- `useRealLights` — реальный прожектор (по умолчанию ВЫКЛ, чтобы не было круга в салоне).

**BlizzardController (метель):**
- `intensity` (0..1) — плотность снега и сила ветра.
- `windDirection` / `windSpeed` — куда и как быстро несёт снег.
- `gustCycleSpeed` — дыхание порывов.
- `areaSize` / `areaHeight` — область спавна снега (рамка видна, если выделить объект).
- `snowflakeSize`, `snowColor`, `streakStretch` — вид снежинок (полосы в метель).
- `fogDensityMin/Max` — густота тумана привязывается к интенсивности метели.
- **Snow cover** — снежный покров: меш с **сугробами по колено** (процедурный, без ассетов),
  с запечённым в вершины освещением. Высота определяется **автоматически** (рейкасты дороги +
  низ машины), поверх — `snowAboveGround` (снег слегка хоронит колёса — это метель):
  `snowCover` вкл/выкл, `snowAutoHeight`, `snowBaseHeight` (ручная высота, если авто выключено),
  `snowDriftDepth` (глубина сугробов, ~0.5 = по колено), `snowWaveFrequency` (частота волн),
  `snowSize`, `snowOpacity`, `snowTint`, `snowTextureScale` (мелкость узора),
  `snowPatchiness` (контраст пятен). Объект называется `Snow_Cover`, пересоздаётся при каждом старте.

## Служебные объекты

- **`HideInGame`** — в Play-режиме отключает только рендерер объекта: коллайдеры и логика
  работают, в редакторе всё видно. Нужен для служебных мешей (Sphere и т.п.), которые
  должны существовать, но не рисоваться. Система исключений из тумана войны (зоны-квадраты)
  **полностью удалена** по решению геймдизайна: салон виден, только когда конус направлен
  на него, как и всё остальное.
- Метод `SetIntensity(v)` — можно рулить из кода/скриптов сюжета.

**CarInteractionManager:** `interactMask` — слой, по которому кликаем (по умолчанию все).

**CustomCursor:** `size`, цвета (`ringColor`/`dotColor`/`hoverColor`), `hotspot` (точка клика внутри картинки).
Хочешь свою картинку — положи PNG и назначь в `customTexture`.

### Камера (Main Camera)

**Ps1Filter:** тоггл `filterEnabled`, в игре — клавиша **F9**.
Работает как URP RenderGraph-пасс: камера рендерится как обычно, фильтр
просто вклинивается после пост-обработки. Никаких Renderer Features и
никакого перенаправления рендера — экран не может стать чёрным от него.
- `pixelHeight` — внутренняя вертикальная резолюция: 240 = честный PS1, больше = чётче.
- `quantizeLevels` — уровней цвета на канал: 5 = чисто как в Buckshot Roulette, 2–3 = жёсткий ретро-бандинг.
- `dither` — дизеринг (держи 0–0.3 для чистой картинки, больше = зернистость).
- `scanlines`, `noise` — сканлайны и шум (по умолчанию почти выключены).

### Курсор

**CustomCursor** на `--- ATMOSPHERE ---`: теперь это стрелка (не прицел).
`useCustomCursor = false` — вернуть системный курсор, ничего не трогая.
Свой PNG — в поле `customTexture`. При наведении на деталь машины стрелка
подкрашивается янтарным.

## Как програмно пользоваться

```csharp
// Запотели окна:
FogOfWarController.Instance.SetWindowVisibility(0.15f);
// Протёрли:
FogOfWarController.Instance.SetWindowVisibility(1f);

// Метель усилилась:
FindObjectOfType<BlizzardController>().SetIntensity(1f);

// Клик по части машины:
CarPartClickable.PartClicked += part => Debug.Log($"Нажали: {part.PartName}");
```
